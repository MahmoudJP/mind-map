# خريطة عقلي 🌳

موقع خريطة ذهنية شخصية بالعربي — شكل مركزي في النص وكل أفكارك متفرّعة منه، بوضع ليلي فخم.

## تشغيل الموقع

افتح **`index.html`** بأي متصفح (دبل-كليك). مفيش أي تنصيب ولا إنترنت مطلوب —
الملف مكتفي بذاته تمامًا (حتى الخطوط العربية مضمّنة جواه)، وشغّال على الموبايل برضه.

## الملفات

| الملف | إيه ده |
|---|---|
| `index.html` | الموقع النهائي الكامل — **ده اللي بتفتحه** (مبني تلقائيًا، متعدلش فيه) |
| `artifact.html` | نسخة النشر كـ Artifact (مبنية تلقائيًا برضه) |
| `src/body.html` | الكود المصدري: الشكل + الجافاسكريبت — **عدّل هنا** |
| `src/fonts.css` | خطوط Tajawal و El Messiri العربية مضمّنة كـ base64 |
| `src/build.sh` | يدمج `fonts.css` + `body.html` وينتج `index.html` و `artifact.html` |

## بعد أي تعديل

عدّل في `src/body.html` وبعدين شغّل:

```bash
bash src/build.sh
```

## أفكارك بتتحفظ فين؟

في **متصفحك** (localStorage) على نفس الجهاز — مش على أي سيرفر، خصوصية كاملة.

- **حفظ نسخة JSON** (من قايمة ⋯) بينزّل نسخة احتياطية على جهازك
- **استيراد نسخة** بيرجّع النسخة دي
- **مسح الخريطة** بيبدأ من جديد (مع رسالة تأكيد)

> نصيحة: اعمل نسخة JSON من وقت للتاني، لأن تنضيف بيانات المتصفح بيمسح المحفوظ.

## المميزات

- **سحب وإفلات** — اسحب أي فكرة وارميها على فكرة تانية عشان تنقلها لفرعها
- **علامة خلصت ✓** — الفكرة تتشطب وتهدى، والفكرة الأم بتوريك عدّاد `2/5`
- **إيموجي على الأفكار** 🔥 + **ربط فكرتين** في فرعين مختلفين بخط منقّط
- **قوالب بداية** — تفريغ ذهني، اتخاذ قرار، تخطيط أسبوع، أو خريطة فاضية
- **تصدير Markdown** 📄 — الخريطة كقايمة متشجّرة بـcheckboxes وملاحظات
- **أفكار النهاردة** ⏱ — نوّر اللي كتبته خلال آخر ٢٤ ساعة
- **خرايط متعددة** 🗺️ — خريطة لمشاعرك وواحدة لشغلك وواحدة لأحلامك، وتنقّل بينهم
- **ملاحظات جوه الأفكار** 📝 — افضفض بنص طويل مخبّي جوه أي فكرة
- **نقل فكرة لفرع تاني** ⇄ — دوس زرار النقل وبعدين اختار الفرع الجديد
- **وضع التركيز** 🧘 — فرع واحد يضوي والباقي يهدى بأنيميشن تنفّس
- **تصدير صورة PNG** 🖼️ — الخريطة كلها صورة جاهزة للحفظ أو المشاركة
- **تغيير شكل المركز** ✦ — ١٤ تصميم جاهز أو صورة من جهازك
- **بحث عربي ذكي** (`/`) — بيلاقي «أهداف» حتى لو كتبت «اهداف»، وEnter بينقّلك بين النتايج
- إضافة أفكار غير محدودة على أي عدد مستويات، والدايرة بتوسّع نفسها تلقائيًا
- اختصارات: `Enter` فكرة زميلة · `Tab` متفرّعة · `Space` تعديل · `Delete` حذف
- تراجع/إعادة (`Ctrl+Z` / `Ctrl+Shift+Z`) وزرار **رجّع** جوه رسالة الحذف
- طيّ/فتح كل الفروع بضغطة · **تثبيت على الشاشة الرئيسية** زي تطبيق
- تذكير لطيف لو عدى أسبوع من غير نسخة احتياطية
- **لغتين: عربي وإنجليزي** 🌐 — زرار `EN` في الشريط بيقلب الواجهة كلها والاتجاه معاها
  (أفكارك وملاحظاتك بتفضل زي ما هي — الترجمة للواجهة بس)
- **تنقّل بالأسهم** ←→↑↓ بين الأفكار من غير ماوس
- وضع ليلي ونهاري · واجهة RTL/LTR كاملة · شغّال موبايل بمنيو مخصوص
